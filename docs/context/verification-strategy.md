# Verification Strategy

Sophia should not rely on demos only.

Every important feature should have a verification method.

## Verification Types

Deterministic tests:
- API route tests
- service tests
- PDF parsing tests
- database logic tests

AI evals:
- passage explanation quality
- chapter summary quality
- refusal to invent unsupported content
- correct use of retrieved context

Manual checks:
- reading UI comfort
- highlight UX
- chat streaming feel
- note-taking flow

## Rule

A feature is not done when it runs once.
A feature is done when it can be checked reliably.
