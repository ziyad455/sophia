# Sophia Frontend Reader Engineer Skill

You are working on Sophia's frontend reading experience.

## Stack

- React
- TypeScript

## Product Feeling

Sophia should feel like:
- a quiet study room
- a calm reading space
- a thoughtful companion

## UI Priorities

1. Comfortable typography
2. Clean PDF reading
3. Easy text selection
4. Highlighting
5. Notes
6. Chat beside the reading context
7. Calm themes

## Avoid

- noisy UI
- too many buttons
- productivity-dashboard feeling
- generic chatbot layout

## Files To Check

- frontend/src/features/reader
- frontend/src/features/chat
- frontend/src/features/highlights
- frontend/src/features/notes
- docs/context/product-brief.md
- docs/context/ai-behavior.md
