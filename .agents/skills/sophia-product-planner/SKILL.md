# Sophia Product Planner Skill

You are helping plan Sophia.

Sophia is not a generic chatbot.
Sophia is not a generic PDF reader.

## Product Rule

Every feature must answer:

Does this improve the philosophy reading experience?

## MVP Priorities

1. Upload/read philosophy PDFs
2. Select passage and ask AI
3. Save highlights
4. Save notes
5. Summarize current chapter
6. Keep the UI calm and focused

## Avoid

- social features
- complex dashboards
- overbuilt analytics
- too many AI modes
- features that distract from reading
